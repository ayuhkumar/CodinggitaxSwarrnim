### Assignment 1 – Create and Resolve a Merge Conflict (Mandatory)

**Goal:** Create a real conflict with two feature branches and resolve it on GitHub.

1. Create a new repository on GitHub named `merge-conflict-practice` (or use your practice repo) and clone it.
2. On `main`, create a file `tasks.txt` with:

```text
My Tasks
1. Study Git
2. Complete assignment
3. Review notes
```

3. Commit and push to `main`:
   ```bash
   git add tasks.txt
   git commit -m "Add tasks.txt"
   git push origin main
   ```

4. Create branch `feature/tasks-A`:
   ```bash
   git checkout -b feature/tasks-A
   ```
   Change line 3 from `Review notes` to `Practice merge conflicts`.  
   Commit and push, then open a Pull Request (do **not** merge yet).

5. Switch back to `main` and create branch `feature/tasks-B`:
   ```bash
   git checkout main
   git checkout -b feature/tasks-B
   ```
   Change line 3 from `Review notes` to `Watch Git tutorial`.  
   Commit and push, then open a second Pull Request.

6. Merge the **first PR** (`feature/tasks-A`) successfully.
7. Try to merge the **second PR** (`feature/tasks-B`) → you will see a conflict.
8. Resolve the conflict on GitHub:
   - Open the conflict editor
   - Understand Current vs Incoming changes
   - Decide the final text (you may keep one version, both, or write your own)
   - Remove all conflict markers
   - Mark as resolved → Commit merge → Merge the PR
9. Delete both remote feature branches.
10. Update local main and delete local branches:
    ```bash
    git checkout main
    git pull origin main
    git branch -D feature/tasks-A
    git branch -D feature/tasks-B
    ```

**Submit:**
- Link to the repository
- Screenshot of the conflict editor (showing markers)
- Screenshot of the successfully merged second PR
- Screenshot of `git log --oneline` after `git pull`

### Assignment 2 – Conflict with a Different File (Mandatory)

**Goal:** Practice the same conflict workflow with a new file.

1. On `main`, create `menu.txt`:

```text
Today's Menu
1. Rice
2. Dal
3. Salad
```

2. Commit and push to `main`.
3. Create `feature/menu-A` → change `Salad` to `Raita` → commit → push → open PR.
4. Create `feature/menu-B` (from main) → change `Salad` to `Papad` → commit → push → open PR.
5. Merge first PR, then resolve the conflict on the second PR on GitHub.
6. In the resolution, **manually write a final version** of your choice (do not just accept Current or Incoming).
7. Complete merge, delete remote branches, pull main, delete local branches.

**Submit:**
- Links to both merged PRs
- Screenshot of your manual conflict resolution
- Screenshot of final `menu.txt` content on GitHub `main`

### Assignment 3 – Short Reflection (Mandatory)

Create a file `day12-reflection.txt` and answer in your own words:

1. What causes a merge conflict?

Commit and push this file to `main` (directly or via a small PR).

**Submit:** Content of `day12-reflection.txt` (or screenshot) + commit/PR link.

### Bonus – Resolve Conflict Locally (Optional)

Instead of resolving on GitHub, try resolving a conflict on your local machine:

1. Create two branches that modify the same line of a file.
2. Merge one branch into `main` locally.
3. Merge the second branch → conflict appears in the terminal.
4. Open the file, resolve the conflict markers manually, then:
   ```bash
   git add .
   git commit -m "Resolve merge conflict"
   ```
5. Push the result.

**Submit (optional):** Screenshot of the conflicted file and the final resolution commit.
