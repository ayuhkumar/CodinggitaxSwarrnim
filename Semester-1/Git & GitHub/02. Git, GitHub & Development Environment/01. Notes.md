## 1. What is Git?

**Git** is a **Distributed Version Control System (DVCS)**.

It is a tool that helps developers:
- Track changes in their code
- Keep complete history of every modification
- Work offline
- Collaborate with others safely
- Revert back to any previous version when needed

Git was created by **Linus Torvalds** in 2005.

> In simple words:  
> **Git is the software that runs on your computer and manages versions of your project.**

---

## 2. What is GitHub?

**GitHub** is a **cloud-based platform** (website) that hosts Git repositories.

It allows you to:
- Store your code online
- Share code with others
- Collaborate with team members
- Showcase your projects
- Contribute to open-source projects

GitHub is owned by Microsoft.

> In simple words:  
> **GitHub is an online platform where you can store and share Git repositories.**

---

## 3. Difference between Git and GitHub

| Point              | Git                              | GitHub                              |
|--------------------|----------------------------------|-------------------------------------|
| Type               | Version Control System (Software)| Cloud Platform / Website            |
| Location           | Installed on your local computer | Runs on the internet (cloud)        |
| Main Purpose       | Track changes & manage versions  | Host, share & collaborate on code   |
| Internet Required? | No (works offline)               | Yes (for pushing/pulling)           |
| Created By         | Linus Torvalds                   | GitHub Inc. (now Microsoft)         |
| Example            | The engine                       | The garage / parking place          |

**Important:**  
You can use Git without GitHub, but you cannot use GitHub effectively without Git.

## 4. Easy Example: Taxi Service vs Uber/Ola

| Concept   | Real-life Example      | Meaning                                      |
|-----------|------------------------|----------------------------------------------|
| **Git**   | Taxi Service           | The actual system that manages the ride      |
| **GitHub**| Uber / Ola             | The platform that connects drivers & riders  |

- **Git** is like the taxi service itself (the core system that works).
- **GitHub** is like Uber or Ola – a platform that makes the service easily accessible, shareable, and collaborative.

Just like you need a taxi service to travel, you need Git to manage code.  
Just like Uber makes taxis easily available to everyone, GitHub makes Git repositories easily available online.

## 5. What is a Development Environment (Dev Environment)?

A **Development Environment** is the complete setup of tools that a developer needs to write, test, and manage code efficiently.

### Simple Analogy:
To take notes in class, you need:
- Pen
- Paper
- Notebook

Similarly, to create software, a developer needs a proper **Dev Environment**.

### Common tools in a Dev Environment:
- **Code Editor / IDE** (e.g., VS Code)
- **Version Control** (Git)
- **Code Hosting Platform** (GitHub)
- Terminal / Command Line
- Browser (for testing web projects)
- Package managers, compilers, etc. (as needed)

---

## 6. What is an IDE?

**IDE** stands for **Integrated Development Environment**.

It is a software application that provides comprehensive facilities to programmers for software development.

An IDE normally includes:
- Code Editor
- Terminal / Console
- Debugger
- File Explorer
- Extensions / Plugins support
- Syntax highlighting & auto-completion

---

### Advantages of using an IDE

1. Faster coding with auto-completion and suggestions
2. Easy debugging
3. All tools in one place (editor + terminal + file management)
4. Syntax highlighting (makes code readable)
5. Extension support (extra features)
6. Increases productivity

---

### Disadvantages of IDE

1. Some IDEs are heavy and consume more RAM
2. Can feel complex for absolute beginners
3. Some advanced IDEs are paid
4. May hide underlying concepts if overused

---

### Types of IDE / Code Editors

| Type                  | Description                          | Examples                  |
|-----------------------|--------------------------------------|---------------------------|
| Full IDE              | Complete development environment     | IntelliJ IDEA, Eclipse, Visual Studio |
| Lightweight Code Editor | Fast and simple editors             | VS Code, Sublime Text, Atom |
| Online IDE            | Runs in browser                      | Replit, CodeSandbox, GitHub Codespaces |
| Language Specific IDE | Designed for one language            | PyCharm (Python), Android Studio |

---

### Why VS Code is the Most Popular?

- Free and open-source
- Lightweight and fast
- Excellent extension marketplace
- Built-in terminal
- Great support for many languages
- Available on Windows, Mac, and Linux
- Strong community support
- Perfect for beginners as well as professionals

## 7. Overview of VS Code (Visual Studio Code)

After installation, you will see several important sections:

### Main Parts of VS Code:

1. **Activity Bar** (Left most side)
   - Explorer (files & folders)
   - Search
   - Source Control (Git)
   - Extensions
   - Run & Debug

2. **Side Bar**
   - Shows content based on what you select in Activity Bar (usually File Explorer)

3. **Editor Area** (Center)
   - Where you write and edit code

4. **Panel** (Bottom)
   - Terminal
   - Problems
   - Output
   - Debug Console

5. **Status Bar** (Very bottom)
   - Shows branch name, errors, line number, etc.

### Terminal in VS Code
- You can open the terminal by pressing `` Ctrl + ` `` (Control + backtick)
- This terminal is used to run Git commands and other commands without leaving VS Code

## 8. Overview of GitHub

### What is a Repository (Repo)?
A **repository** is a storage space where your project files and their complete history are stored.

There are two types:
- **Local Repository** → on your computer
- **Remote Repository** → on GitHub

---

### How to Create a Repository on GitHub

1. Login to GitHub
2. Click the **+** icon (top right) → **New repository**
3. Give a repository name
4. Choose Public or Private
5. (Optional) Add README
6. Click **Create repository**

---

### Important Sections on GitHub

| Section       | What you can see / do                     |
|---------------|-------------------------------------------|
| **Profile**   | Your photo, bio, repositories, contribution graph |
| **Repositories** | List of all your projects               |
| **Calendar / Contribution Graph** | Shows your coding activity (green boxes) |
| **Settings**  | Account and repository settings           |
| **Pull Requests & Issues** | Collaboration features               |

The **green contribution calendar** on your profile shows how active you are on GitHub. More green boxes = more contributions.
