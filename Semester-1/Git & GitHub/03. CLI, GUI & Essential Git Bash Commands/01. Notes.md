
#  CLI, GUI & Essential Git Bash Commands  

---

## 1. CLI vs GUI

### What is GUI?
**GUI** stands for **Graphical User Interface**.

- You interact with the computer using **mouse, icons, buttons, and windows**.
- Examples: Windows File Explorer, VS Code interface, GitHub website, Chrome browser.

**Advantages of GUI:**
- Easy to learn for beginners
- Visual and user-friendly
- Less chance of typing errors

**Disadvantages of GUI:**
- Slower for repetitive tasks
- Limited automation
- Difficult to work on remote servers

---

### What is CLI?
**CLI** stands for **Command Line Interface**.

- You interact with the computer by **typing commands** in a terminal.
- Examples: Command Prompt (CMD), PowerShell, **Git Bash**, Terminal on Mac/Linux.

**Advantages of CLI:**
- Very fast and powerful
- Excellent for automation and scripting
- Preferred for professional development
- Works well with Git and servers

**Disadvantages of CLI:**
- Steeper learning curve
- Commands must be typed accurately
- Less visual feedback

---

### Why do we use CLI for Git?

Git was originally designed for the command line.  
Most professional developers use **Git through CLI** (Git Bash) because:

- It gives full control
- All features of Git are available
- Faster once you learn the commands
- Industry standard

> **Note:** Although Git has GUI tools (GitHub Desktop, GitKraken, etc.), learning CLI is essential.

## 2. Installing Git

Git must be installed on your system before you can use Git commands.

### Steps to Install Git (Windows):
1. Go to the official website: [https://git-scm.com](https://git-scm.com)
2. Download the Windows version
3. Run the installer
4. Keep the default options (recommended for beginners)
5. Finish the installation

### Verify Installation:
Open **Git Bash** and type:

```bash
git --version
```
or

```bash
git -v
```

If Git is installed correctly, it will show the version number (example: `git version 2.43.0`).

## 3. Changing Default Terminal in VS Code to Git Bash

By default, VS Code uses **PowerShell** as the terminal on Windows.  
We change it to **Git Bash** because most Git commands are practiced there.

### Steps:
1. Open VS Code
2. Press `Ctrl + ,` (or go to File → Preferences → Settings)
3. Search for: `terminal default profile windows`
4. Select **Git Bash** from the dropdown
5. Open a new terminal (`Ctrl + `` `)

Now every time you open the terminal in VS Code, it will be **Git Bash**.

## 4. Basic Commands in Command Prompt (CMD)

These are simple Windows commands:

| Command | Purpose |
|---------|---------|
| `dir` | Show all files and folders in the current directory |
| `cd` | Show current directory / Change directory |
| `cd foldername` | Move into a folder |
| `cd ..` | Move one level up |

---

## 5. Essential Git Bash Commands (Very Important)

These commands are used **every day**. Master them.

### 5.1 Navigation Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `pwd` | Print Working Directory (shows current location) | `pwd` |
| `cd foldername` | Change directory (move into a folder) | `cd Documents` |
| `cd ..` | Move one level up | `cd ..` |
| `cd ../..` | Move two levels up | `cd ../..` |
| `cd ~` | Go to home directory | `cd ~` |
| `cd -` | Go back to the previous directory | `cd -` |

---

### 5.2 Listing Files & Folders

| Command | Purpose |
|---------|---------|
| `ls` | List files and folders |
| `ls -l` | List in long format (detailed view) |
| `ls -a` | List all files including hidden files |
| `ls -la` | Long format + hidden files (most useful) |

---

### 5.3 Creating & Removing Directories

| Command | Purpose | Example |
|---------|---------|---------|
| `mkdir foldername` | Create a new folder | `mkdir Project` |
| `rmdir foldername` | Remove an **empty** folder | `rmdir Project` |

---

### 5.4 File Operations

| Command | Purpose | Example |
|---------|---------|---------|
| `touch filename` | Create a new empty file | `touch index.html` |
| `echo "text" > file` | Create a file with content | `echo "Hello" > test.txt` |
| `cat filename` | Show content of a file | `cat test.txt` |
| `cp file1 file2` | Copy a file | `cp test.txt backup.txt` |
| `cp -r folder1 folder2` | Copy a folder (recursively) | `cp -r Project ProjectBackup` |
| `mv oldname newname` | Rename a file/folder | `mv test.txt hello.txt` |
| `mv file folder/` | Move a file into a folder | `mv hello.txt Documents/` |
| `rm filename` | Delete a file | `rm hello.txt` |
| `rm -r foldername` | Delete a folder and its content | `rm -r Project` |
| `rm -rf foldername` | Force delete a folder (be careful!) | `rm -rf temp` |

> **Warning:** `rm -rf` permanently deletes files/folders. Use with caution.

---

### 5.5 Other Useful Commands

| Command | Purpose |
|---------|---------|
| `clear` | Clear the terminal screen |
| `date` | Show current date and time |
| `whoami` | Show the current username |
| `history` | Show previously typed commands |
| `git --version` | Check installed Git version |
| `exit` | Close the terminal |

---

## 6. Important Notes

1. Git Bash commands are **case-sensitive**.
2. Always check your current location using `pwd` before creating or deleting files.
3. Use `ls -la` frequently to see hidden files (especially `.git` folder later).
4. Prefer `rm -r` over `rm -rf` unless you are very sure.
5. You can use the **up arrow key** to recall previous commands.

## 8. Key Takeaways 

- **GUI** is visual (mouse + icons). **CLI** is text-based (commands).
- We use **Git Bash** (CLI) for Git because it is powerful and professional.
- Always verify Git installation using `git --version`.
- Change VS Code terminal to **Git Bash** for convenience.
- Master the basic navigation and file commands — you will use them daily.
