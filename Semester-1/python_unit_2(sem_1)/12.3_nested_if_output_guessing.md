# Important Rules to Remember

## Rule 1 — Outer Branch First

First decide which outer branch will execute:

```text
Outer if
   ↓
if TRUE → enter this block

if FALSE
   ↓
check outer elif

if all FALSE
   ↓
outer else
```

Once an outer branch is selected, follow the nested conditions inside that branch.

---

## Rule 2 — `if-elif-else` Checks from Top to Bottom

```python
if condition_1:
    print("A")
elif condition_2:
    print("B")
elif condition_3:
    print("C")
else:
    print("D")
```

Python checks from top to bottom.

As soon as one condition becomes `True`, its block executes and the remaining `elif` and `else` blocks in that chain are skipped.

---

## Rule 3 — Nested `if` Has Its Own Decision Chain

An inner `if-elif-else` is a separate decision chain from the outer one.

```python
if outer_condition:

    if inner_condition:
        print("A")
    elif another_inner_condition:
        print("B")
    else:
        print("C")
```

First the outer condition is evaluated. Only if the program enters that block does it evaluate the inner decision chain.

# Teacher Tip

Ask students to visualize nested conditions as a tree:

```text
Outer if
├── Inner if
├── Inner elif
└── Inner else

Outer elif
├── Inner if
├── Inner elif
└── Inner else

Outer else
├── Inner if
├── Inner elif
└── Inner else
```

The main mental model is:

> **First select the outer branch. Then solve the nested decision inside that branch.**

Do not try to evaluate every condition at once. Trace the program one level at a time.
