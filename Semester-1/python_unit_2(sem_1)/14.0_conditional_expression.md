# Conditional Expression — Conversion Practice

## Objective

Convert the given multi-line `if-elif-else` code into a **single-line Conditional Expression**.

### Basic Syntax

```python
value_if_true if condition else value_if_false
```

### Multiple Conditions

```python
result = "A" if condition1 else "B" if condition2 else "C"
```

# Important Rules to Remember

### Rule 1

Basic Conditional Expression:

```python
result = "Yes" if condition else "No"
```

### Rule 2

Multiple conditions:

```python
result = "A" if condition1 else "B" if condition2 else "C"
```

### Rule 3

Nested Conditional Expression:

```python
result = ("A" if condition1 else "B") if condition2 else "C"
```

### Rule 4

`else` is mandatory in a Conditional Expression.

This is valid:

```python
result = "Pass" if marks >= 40 else "Fail"
```

This is **not valid**:

```python
# ❌ Invalid
result = "Pass" if marks >= 40
```

### Rule 5

Do not make very complicated Conditional Expressions unnecessarily.

Prefer:

```python
if marks >= 90:
    result = "A"
elif marks >= 75:
    result = "B"
else:
    result = "C"
```

over an extremely long one-liner when readability becomes difficult.
