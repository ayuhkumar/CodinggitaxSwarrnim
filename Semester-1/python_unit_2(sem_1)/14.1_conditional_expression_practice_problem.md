# Conditional Expression — Practice Problems

## Objective

Solve the following problems using **Python Conditional Expressions**.

### Basic Syntax

```python
result = value_if_true if condition else value_if_false
```

### For Multiple Conditions

```python
result = value1 if condition1 else value2 if condition2 else value3
```

### Important

For this practice set:

* Use Conditional Expressions instead of multi-line `if-else`.
* Try to store the result in a variable.
* Avoid unnecessary multi-line `if`, `elif`, and `else`.
* For nested problems, use nested Conditional Expressions.
* Do not use loops unless the question specifically requires them.

# Practice Rule

For every problem, first think:

```text
What value should I return if the condition is True?
What value should I return if the condition is False?
```

Then write:

```python
result = TRUE_VALUE if CONDITION else FALSE_VALUE
```

For multiple conditions:

```python
result = VALUE1 if CONDITION1 else VALUE2 if CONDITION2 else VALUE3
```

For nested conditions:

```python
result = (VALUE1 if CONDITION1 else VALUE2) if CONDITION2 else VALUE3
```

**Goal:** Write clean, readable Conditional Expressions rather than simply trying to make the code as short as possible.
