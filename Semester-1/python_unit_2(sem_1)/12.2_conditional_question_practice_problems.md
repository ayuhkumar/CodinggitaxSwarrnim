# Quick Syntax Revision

## 1. `if`

Use when you need to perform an action **only when a condition is true**.

```python
if condition:
    statement
```

Example:

```python
if age >= 18:
    print("Eligible")
```

### Mental Model

**One possible action → `if`**

---

## 2. `if-else`

Use when there are **two alternatives**.

```python
if condition:
    statement_1
else:
    statement_2
```

Example:

```python
if num % 2 == 0:
    print("Even")
else:
    print("Odd")
```

### Mental Model

**A OR B → `if-else`**

---

## 3. `if-elif-else`

Use when there are **multiple alternatives**.

```python
if condition_1:
    statement_1
elif condition_2:
    statement_2
elif condition_3:
    statement_3
else:
    statement_4
```

Example:

```python
if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 60:
    print("C")
else:
    print("D")
```

### Mental Model

**A OR B OR C OR D → `if-elif-else`**

---

# Important Concept: How `if`, `elif`, and `else` Connect

An `elif` is connected to the `if` immediately before it.

An `else` belongs to the nearest preceding `if`/`elif` chain.

Example:

```python
if condition_1:
    print("A")

elif condition_2:
    print("B")

else:
    print("C")
```

All three are part of **one decision chain**.

However:

```python
if condition_1:
    print("A")

if condition_2:
    print("B")
else:
    print("C")
```

Here, the `else` is connected **only to the second `if`**.

This distinction is especially important when solving problems such as finding the greatest of three numbers.

---

# Final Learning Goal

After completing these 15 sets, students should be able to decide:

| Requirement | Recommended Structure |
|---|---|
| Only perform an action when a condition is true | `if` |
| Choose between two alternatives | `if-else` |
| Choose between multiple alternatives | `if-elif-else` |
| Check independent conditions that can all be true | Multiple separate `if` statements |
| Choose exactly one result from multiple categories | `if-elif-else` |

The main goal is not just to memorize the syntax. Students should first identify **how many possible decision paths the problem has**, and then select the appropriate conditional structure.
