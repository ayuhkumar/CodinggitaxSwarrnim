# Key Learning Goal

Students should be able to recognize the difference between:

### Simple Nested Condition

```python
if condition:
    if another_condition:
        ...
```

### Nested `if-else`

```python
if condition:
    if another_condition:
        ...
    else:
        ...
else:
    ...
```

### Nested `if-elif-else`

```python
if condition:
    if condition_1:
        ...
    elif condition_2:
        ...
    else:
        ...
```

### Nested `if-elif-else` Inside Every Outer Branch

```python
if outer_condition:
    if inner_condition_1:
        ...
    elif inner_condition_2:
        ...
    else:
        ...

elif another_outer_condition:
    if inner_condition_3:
        ...
    elif inner_condition_4:
        ...
    else:
        ...

else:
    if inner_condition_5:
        ...
    elif inner_condition_6:
        ...
    else:
        ...
```

The main objective is to make students comfortable with **indentation, decision flow, nested conditions, and choosing the correct branch** before moving to more complex programs.
